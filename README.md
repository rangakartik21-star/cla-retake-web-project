# StudySpace - CLA Retake Web Project

A simple responsive front-end website created for the September 2026 CLA retake submission.

## Features

- Responsive navigation bar using Flexbox
- Google Font (Inter) for improved typography
- Responsive card layout using CSS Grid
- Mobile-friendly layout using media queries
- Hover effects and smooth transitions
- Sticky navigation bar
- Smooth scrolling between sections
- Mobile navigation menu using JavaScript
- Simple study-goal form with JavaScript validation
- Semantic HTML and accessible labels

## Files

- `index.html` - page structure and content
- `styles.css` - layout, colors, typography and responsive design
- `script.js` - mobile menu and form interaction
