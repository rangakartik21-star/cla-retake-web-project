# Personal Resume Website - CLA Retake September 2026

This folder contains the updated personal resume website for the CSS assignment.

## CSS improvements applied

- Added a sticky navigation bar using Flexbox.
- Used Google Fonts (DM Serif Display and Inter) for a stronger visual hierarchy.
- Applied a consistent warm-neutral colour palette with reusable CSS variables.
- Used class, ID and element selectors for organised styling.
- Used CSS Grid for the hero, profile, education, experience and skills sections.
- Added resume cards, rounded borders, spacing, shadows and hover effects.
- Improved alignment, typography and text formatting throughout the page.
- Added responsive media queries for tablet and mobile layouts.
- Added smooth scrolling and section spacing for better navigation.
